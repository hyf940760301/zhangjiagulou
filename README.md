# 张家古楼 · Zhangjia Gulou

《盗墓笔记》中张家古楼的**七层可视化重建**。

几何用 Blender 精确搭建，材质与光影由 World Labs Atlas 的**深度引导生成**产出 ——
几何可信度来自建模，质感来自 AI，两者各司其职。

> 巴乃张家古楼：原著十一层，沉入湖底只露七层。本仓库建七层可见部分。

---

## 在线看

打开 `index.html`（或用 GitHub Pages 部署本仓库根目录）：

- 底部按钮切楼层
- **`▶ 环视一圈`** —— 自动把当前层所有机位走一遍（每 1.2 秒切一张，走完自动停）
- `←` `→` 换机位，`↑` `↓` 换楼层
- 右上角平面图显示当前机位与朝向

共 **7 层 · 40 张照片级图**（每张 2560×1440）。

## 工作流

```
① 深度     Blender 20 台相机射线求交 → 1280×720 线性深度 EXR（约 6 分钟/层）
② 体检     标记"扎进物件"的机位（深度中位数 < 1.2 m 判废）
③ 生成     atlasChisel 一次请求 15 个核心机位（约 31 秒）
④ 装配     图 + 相机位姿 → 环视页
```

### 15 个核心机位

```
B0–B7        半径 8，看整层        8 帧
A0 A2 A4 A6  近景正向              4 帧
U0 U1 U2     仰视天窗              3 帧
```

深度仍渲 20 个机位，只提交 15 个 —— 以后要加机位不用重渲。

### 一条命令

```bash
source .tools/atlas-env.sh          # 需要 WLT_API_KEY
./pipeline/zjl-floor.sh 3           # 单层
./pipeline/zjl-floor.sh 1 2 4 5 6 7 # 批量
```

脚本幂等：深度在就跳过、体检在就跳过、生成结果在就跳过。**中断重跑不会重复花钱。**

详细说明见 [`docs/WORKFLOW.md`](docs/WORKFLOW.md)。

## 每层机位必须避让的东西

各层陈设不同，机位跟着变 —— 这些都是渲出深度才发现的：

| 层 | 撞到什么 | 处理 |
|---|---|---|
| 4 玄龟 | 龟壳半径正好 4 m | 环半径 6.2 + 转 22.5° |
| 5 族长棺 | 棺床占满中轴 | 环抬高 1.5 m |
| 6 藏宝 | 箱柜高 1.55 m 且铺满 | 半径 5.4 + 抬高 |
| 7 玉棺 | 天井角柱与中柱 | 半径 5.0 + 转 22.5° |

**深度图是"相机有没有扎进墙里"的唯一证据。**

## 三个必须记住的坑

**1. EXR 写不进去** —— `img.pixels = numpy_array` 会静默失效，文件全是 0：

```python
img.pixels.foreach_set(arr.ravel())   # 唯一可靠写法
```

**2. depsgraph 会失效** —— 新增相机后旧 depsgraph 失效，`ray_cast` 全部 miss，
深度全 0。必须在函数内每次重新取。

**3. 管道会杀死长任务** ——

```bash
python chisel_all.py 1 2 | head -20   # ✗ SIGPIPE，任务根本没跑
python chisel_all.py 1 2 > log 2>&1   # ✓
```

前两条曾导致两次全盘失败（生成结果全是黑底白线）。

## 重构时反复踩的两条

**1. 有四根柱子的房间，机位只能走轴线。**
45° 对角机位会正好穿过 (±6.5, ±6.5) 的柱子，渲出来是一堵柱墙。

**2. 先用 Blender 干图验构图，再花积分。**
直接从深度进生成，一旦机位错了就是白花钱；干图 30 秒一张，先看再跑。

**3. 生成器的"理解"会压过几何。**
二层铁人俑做了四版（小像 / 3 米 / 4 米带肩甲 / 带长戟），每一版都被读成"悬挂的布囊" ——
只有轮廓的深度，和被吊起来的东西，在生成器眼里是一样的。最后接受了"裹在铁壳里的人形"。

## 关于泼溅

试过用 `posedImages2Splats` 把这些图重建为可自由行走的高斯泼溅（5,000 积分/次）。
**结论是不建议**：源图本身接近黑白，泼溅忠实继承了灰度；加上 200 万点铺满整层，
表面偏糊。**这一层的交付用"图 + 环视"更合适。**
